# Random Joke Generator

## Overview

Random Joke Generator is a fun and interactive web application that fetches random jokes from an external API and displays them dynamically to users.

## Features

* Fetches random jokes using API
* Responsive user interface
* Loading spinner while fetching data
* Simple and user-friendly design
* Dynamic content update without page reload

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript
* Fetch API

## How It Works

1. User clicks the “Joke” button.
2. JavaScript sends a GET request to the jokes API.
3. A loading spinner is displayed while data is being fetched.
4. The API returns a random joke in JSON format.
5. The joke is displayed dynamically on the webpage.

## API Used

https://apis.ccbp.in/jokes/random
